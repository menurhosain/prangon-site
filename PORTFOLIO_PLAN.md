## 4. Design direction

> **The built page changed this:** it uses a limewash-green wall background with the hand-painted JAARDO signboard as the hero (Alfa Slab One + Baloo Da 2 + Hind Siliguri). Cream appears only on the signboards. Section numbers and the marquee were dropped. See `styles.css` for the final tokens.

**Concept: "Old Bengal, new edit."** The page should feel like the JAARDO grid: warm, tactile and nostalgic, with modern editorial layout and generous whitespace. Avoid generic dark-mode tech portfolio styling.

### Colour palette (sampled from your assets)
| Token | Hex | Source |
|---|---|---|
| `--paper` | `#F3EBDD` | JAARDO fabric-note background (page background) |
| `--ink` | `#1C1A17` | Text |
| `--brick` | `#9E3B2C` | Red-brick wall / signboard film (primary accent) |
| `--limewash` | `#7E8A4A` | Green campaign walls |
| `--golapi` | `#E7B7C3` | Golapi shirt (soft highlight) |
| `--mustard` | `#D9A441` | Ronaldinho crown / thumbnails (stats, hover) |
| `--plaid-blue` | `#2C7BC0` | Blue plaid shirt (use sparingly) |

Optional dark section (memes/art): `#141210` background with `--paper` text, so the playful work reads as a different chapter.

### Typography (Google Fonts)
- Display: **Fraunces** or **Instrument Serif**. Serif, editorial, echoes the JAARDO wordmark.
- Body/UI: **Inter** or **Manrope**.
- Bangla: **Tiro Bangla** for display, **Hind Siliguri** for body.
- Use huge display sizes (`clamp(3rem, 9vw, 9rem)`) for section titles. Small uppercase tracked labels for "01 — …".

### Texture and details
- Subtle paper grain overlay (inline SVG noise, about 4% opacity).
- Thin rules and index numbers (01–05), like a magazine.
- Mixed Bangla and English throughout, the same way the assets mix them.
- Rounded phone frames for 9:16 reels. Sharp edges for 16:9 films.

### Responsive
- Desktop ≥1100px: 12-column grid, max width 1280px.
- Tablet: 2-column bento. Phone reels in a horizontal scroll-snap row.
- Mobile ≤600px: single column with 16px gutters. Reels scroll-snap horizontally. Wide films at full width.

### Interactions (CSS first, minimal JS)
- Section videos: `autoplay muted loop playsinline` with poster images, plus `preload="none"` for anything below the fold.
- Documentary video: `controls`, no autoplay, because the audio matters.
- Optional ~20 lines of vanilla JS: an IntersectionObserver that plays and pauses videos when they enter or leave the viewport. This saves bandwidth and battery.
- Hover: images scale 1.03 and a caption slides up. Thumbnail cards tilt slightly.
- Marquee: pure CSS `@keyframes` translateX.
- Scroll reveal: CSS `animation-timeline: view()` with a fallback where nothing is hidden.
- `prefers-reduced-motion`: stop the marquee and autoplay.

## 6. Asset prep (required before building)

The raw files are too heavy for the web (one is 252 MB). Plan:

1. **Rename to web-safe slugs**, no spaces and no Bangla in file names:
   ```
   assets/
     img/  headshot.jpg  thumb-satyajit.jpg  thumb-mourinho.jpg  thumb-tagore.jpg
           jaardo-still.jpg  jaardo-grid.png  art-dinho.jpg  art-face.jpg
           art-420.jpg  art-baker-bhai.jpg  art-marzuk.jpg  meme-page.jpg
     video/ jaardo-signboard  jaardo-lookbook  jaardo-plaid  jaardo-carrom
            jaardo-paperboat  jaardo-lantern  jaardo-callouts  jaardo-fabric
            jaardo-form3  doc-mourinho  meme-gta-intro  meme-natok-titles
     poster/ <same names>.jpg   (first strong frame of each video)
   ```
2. **Compress video** (ffmpeg is installed):
   - Loops (muted): H.264, CRF 26–28, max 720p width for 9:16 / 1280 for 16:9, audio stripped (`-an`), `-movflags +faststart`. Target **under 3 MB each**.
   - Optional WebM (VP9) versions as an extra `<source>`.
   - Documentary: keep audio (AAC 128k), 720p, CRF 24.
3. **Posters**: one JPG frame per video (`ffmpeg -ss 2 -frames:v 1`).
4. **Images**: export WebP at 1600px max (thumbs and art) or 900px (headshot, phone screenshots), plus JPG fallback. Target under 250 KB each.
5. **Total page weight goal:** under 5 MB initial load, under 40 MB fully scrolled.
